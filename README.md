# TwitterPhp

Aplicação web desenvolvida em PHP que simula as funcionalidades essenciais de uma rede social baseada em microblogging (estilo Twitter).

## Sobre o Projeto

O projeto foi construído para praticar e demonstrar conceitos de desenvolvimento web backend e frontend com PHP, permitindo que os usuários criem contas, autentiquem-se, publiquem tweets, sigam outros usuários e visualizem a linha do tempo.

## Funcionalidades

* Autenticação e controle de sessão de usuários.
* Cadastro de novos usuários.
* Publicação de mensagens (tweets).
* Listagem e acompanhamento da linha do tempo.
* Sistema para seguir ou deixar de seguir outros usuários.

## Tecnologias Utilizadas

* PHP
* HTML / CSS
* JavaScript
* Banco de Dados Relacional (MySQL)

## Como Executar

1. Certifique-se de ter um ambiente de servidor local configurado com suporte a PHP e MySQL (como XAMPP, WampServer ou Docker).
2. Clone este repositório ou baixe os arquivos no diretório raiz do seu servidor web (ex: `htdocs` ou `www`).
3. Importe o arquivo de banco de dados correspondente (se houver) para o seu gerenciador MySQL.
4. Configure as credenciais de acesso ao banco de dados no arquivo de conexão do projeto.
5. Acesse o projeto através do seu navegador no endereço local correspondente (ex: `http://localhost/TwitterPhp/`).
